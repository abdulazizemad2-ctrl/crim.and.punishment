# الاختبار المحاكي لمادة مبادئ علمي الإجرام والعقاب · MED

اختبار تفاعلي من ملخصات أبو عماد لمادة **مبادئ علمي الإجرام والعقاب** (الفصل التمهيدي والبابان الأول والثاني)، فيه 60 سؤالاً (32 اختياراً و28 مقالياً) مطابقة لملخص الـ MED وتحديد الدكتور.

- النماذج الأربعة بهيكل الاختبار (8 اختيارات + 7 مقالي)، ونموذج عشوائي جديد
- اختبار شامل، واختبار سريع بمؤقت، وبطاقات المقالي، واختبار حسب الموضوع
- مراجعة الأخطاء، والأسئلة المعلّمة، ونتيجة لكل موضوع

⛔ هذا الاختبار جهدٌ خاص بـ ملخصات أبو عماد للمشتركين في الملخص، ولا يجوز نشره أو تداوله أو بيعه إلا بإذن مسبق.
